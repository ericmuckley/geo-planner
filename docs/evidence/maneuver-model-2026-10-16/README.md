Read [the model report](../../archive/maneuver-routing-model.md) for scope and limitations. - `first-summary.json`, `repeat-summary.json`: every source attachment, bounded case, replay, interior target/cost and resource observation.
- `first-manifest.json`, `repeat-manifest.json`, `first-run-identity.json`: immutable model/source/worker identities and artifact checksums.

- `first-source-samples.osm`: original source records for the two real examples and alternative approaches; unchanged on repeat. © OpenStreetMap contributors, ODbL.
- `repeat-native-verification.json`: compiler/binary identity, actual cost/bitmap/interior comparison counts and one native timing observation per case.
- `comparison.json`: deterministic checks generated by `analyze.py`.

With original local artifacts present, run from the repository root:

```bash
python3 docs/evidence/maneuver-model-2026-10-16/analyze.py
python3 docs/evidence/native-routing-2026-10-16/analyze.py
```

The first command checks first/repeat results and all v2 graph/oracle artifacts, verifies v1 source/graph/field checksums, confirms all accepted maneuvers block at final entry and verifies the native executable matches the earlier binary. The second also checks preserved v1 native outputs and source hashes. Neither command computes new routes or uses networking. Full oracle cost vectors remain in ignored `data/model-pilot/downtown-maneuvers-v2/oracles/`; manifests retain their hashes.
