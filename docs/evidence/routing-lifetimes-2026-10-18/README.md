# Routing lifetime evidence — October 18, 2026

Read [the findings and exact commands](../../routing-preparation-lifetimes.md) first. This experiment changes preprocessing memory ownership on frozen cached inputs. It spends no provider quota and builds no larger graph.

Run the saved comparison from the repository root:

```sh
python3 -B docs/evidence/routing-lifetimes-2026-10-18/analyze.py
```

`analyze.py` checks exact IDs/XML/census and six-fixture preparation results, all frozen graph/audit/source/CSR/gzip parity results, recipe hashes, the limited importer function-body changes, cgroup policy/events, and the reused independent/native evidence identities and comparison counts. `comparison.json` saves its output. This analysis does not reload large graphs, issue routes or create new performance measurements.

Files prefixed `isolated-` and `batched-` are raw preparation reports and identities. `keys-` files are raw import parity reports/manifests/identities. `old-` records retain baseline preparations, current build/rebuild and equality-oracle manifests. `frozen-` records are reused qualification/native evidence, with no fresh search run. `validation.json` records exact check/workload commands, output hashes and integrity checks; adjacent logs preserve their output.

Large products, intermediate reference batches, SQLite census files, sampling/checkpoint progress and frozen recipe copies stay in ignored `data/coverage-pilot/lifetime-*-v1` and `data/keyed-pilot/keys-v1-*` directories. Reports list their hashes. Keep all previous attempts. Use fresh output names/series to reproduce; the defaults are sealed.

Complete cgroup peaks include child processes and verification reads. Worker/child RSS and sampled anonymous/file maxima are separate scopes. Single-run host/cache/VM conditions are uncontrolled; final small metadata writes, Docker startup and module imports are outside the checkpoint scope. All capped workloads use two CPUs/4 GiB RAM/no swap/no network/read-only inputs. No HTTP/browser/Vercel or real-world border correctness measurement is claimed.
