# Where Geo Planner stands

Updated October 22, 2026. The app now has a first **coarse contiguous-US estimator**, independent of routing-provider quotas.

- **Working:** choose a US land origin, compute a filled six-, ten- or twelve-hour estimate, inspect model warnings/timings, save/replay cloud-backed queries and runs and export JSON. Start with `npm run dev`; no database, worker, Python, Docker or routing API key is needed.
- **Small deployment:** a bundled 1.8 MB road-informed grid runs inside the existing TypeScript server. The generated Vercel function is about 5.6 MB and computes contours locally with outbound fetches rejected. An actual cloud deployment remains to be verified.
- **Deliberately coarse:** 7–11 km display cells, generalized Natural Earth roads, assumed 25 km/h land travel (including places without roads) and 45–90 km/h major roads. Traffic, turns, terrain, precise road access, ferries and international crossings are unmodeled. Display resolution is not an accuracy guarantee; driving-time accuracy has not been calibrated.
- **Checked:** thirty server tests, live PostgreSQL persistence/isolation/concurrent-merge/retention checks, browser save/reload/model replay, typecheck, Biome and both builds pass. The earlier coarse milestone retains its 42 representative origin/budget cases. These establish software behavior and local packaging, not real travel-time accuracy or cloud performance. [Model and evidence](coarse-estimator.md).
- **Cloud history works:** the reviewed additive migration is applied to the configured cloud PostgreSQL database. New saves back up automatically; existing browser history uploads through the backup button. Twenty summaries are private to each browser; local saving/export and retry remain available. No accounts or cross-device sync yet. [Evidence](evidence/saved-history-2026-10-22/README.md).
- **Next:** verify a real Vercel preview, then refine the largest observed model errors. Database, routing settings and private cookie values stay server-only or in ignored local files.
- **Preserved reference:** the detailed two-hour regional OSM engine remains at `/experiment`. Its exact rebuild/proofs pass, but longer regional expansion and memory optimization are parked. The separate connected-provider option retains its hosted 60-minute cap. [Detailed baseline](two-hour-region.md) and [memory result](six-hour-preflight.md#memory-follow-up).
