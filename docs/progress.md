# Where Geo Planner stands

Updated October 22, 2026. **Nationwide v5 is active locally and ready for deployment review. Production remains verified v4.**

- **Working:** arbitrary supported US land origins, filled 1–12-hour estimates, 6/10/12h presets, map controls, warnings, timings, cloud-backed/browser-local history and export. Estimation needs no database, worker, Python, Docker or routing key.
- **Nationwide roads:** all 48 contiguous states plus DC contribute Census primary/secondary roads alongside Natural Earth. The same geometry, speed and paid-transfer rules apply everywhere; there are no named-route or region exceptions. V5 adds 36,742 links and lowers 73 existing costs. [Source preparation](evidence/coarse-national-2026-10-22/README.md).
- **Practical local startup:** the 40.0 MB model generates a 43.8 MB Vercel function. Reusable geography indexing keeps full validation and reduces first local computation from 22.2 seconds to 2.46–2.47 seconds in three fresh packaged processes. Incremental retained decoded storage is 32.44 MB; 153,477 inputs keep retained memory bounded. Cloud cold starts/peak memory remain unmeasured. [V5 evidence](evidence/coarse-v5-2026-10-22/README.md).
- **Checked:** 51 server tests, fifteen geometry fixtures, 42 national API cases, all 35 saved comparison costs and reconstructed paths, check/typechecks and both builds/handler pass. Local Chrome verifies inland 6h/rural 10h/coastal 12h, visible source notices and new fixture Cloud saved → reload → Replay. Seven saved cases improve versus v4, 28 unchanged, none regress. These development comparisons do not prove nationwide driving accuracy.
- **Deliberately coarse:** 7–11 km display cells, assumed 25 km/h land travel and 55–105 km/h roads. Nearby crossings merge, one supplemental road per cell limits access and repeated local transfers can remain slow. Traffic, turns, terrain, actual access, ferries and international crossings are unmodeled. Cell size is not an error bound. [Model](coarse-estimator.md).

Persistence is unchanged; the full live DB integration suite was not rerun. No accounts/cross-device sync yet. [Existing evidence](evidence/saved-history-2026-10-22/README.md).
